### 2.2. File Upload API
The serverless backend API was updated with a new endpoint:
- **Endpoint:** `POST /generate-upload-url`
- **Functionality:** Accepts a filename and content type, and returns a presigned S3 URL that grants temporary (5 minutes) `PUT` access to a unique key in the `webwaka-uploads-production` bucket.
- **Security:** The Lambda function was granted specific IAM permissions to generate these presigned URLs for the uploads bucket only.
### 2.3. Frontend Implementation
The frontend application was updated to include a file upload interface:
- **UI:** A file input and an "Upload File" button were added.
- **Workflow:**
  1. User selects a file.
  2. Frontend calls the `/generate-upload-url` endpoint.
  3. Frontend uses the returned presigned URL to upload the file directly to S3.
  4. A success message is displayed with the S3 key of the uploaded file.
