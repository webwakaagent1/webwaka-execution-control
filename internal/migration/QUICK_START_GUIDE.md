## 🔄 Keeping Notion and GitHub in Sync

### The Rule
**Notion is now the single source of truth.**

If Notion and GitHub disagree, Notion wins.

### Sync Protocol

**For Constitution documents**:
1. Propose changes in GitHub (Pull Request)
2. Get founder approval
3. Merge to GitHub
4. Sync to Notion within 24 hours

**For Phase reports**:
1. Update in Notion first
2. Export to GitHub when finalized
3. Get founder approval
4. Merge to GitHub

**For Verification reports**:
- Notion only (no GitHub sync required)
- Reports are immutable once published
