# WebWaka Execution Control: Documentation Index

**Welcome to the WebWaka Execution Control repository!** This document is the central hub for all project documentation. Its purpose is to help you quickly find the information you need based on your role and objective.

---

## 1. How to Use This Documentation

This system is designed around a few key principles:

1.  **Single Source of Truth:** All official documents are in this GitHub repository.
2.  **Centralized Indexes:** Instead of searching for individual files, use the master index for each category.
3.  **Link-Based Communication:** All communication about documents (prompts, reports, handovers) should use direct links to the files in this repository.

### Quick Start: What are you here to do?

- **I am the Founder and I need to...**
    - **Approve a phase:** See the `EXECUTION_LEDGER.md` and the relevant report in the [Completion Report Index](reports/COMPLETION_REPORT_INDEX.md).
    - **Review the project status:** See the `EXECUTION_LEDGER.md`.
    - **Understand the project governance:** See `GOVERNANCE.md`.

- **I am the Coordinator Agent and I need to...**
    - **Assign a new task:** Find the correct link in the [Phase 1 Prompt Links](docs/PHASE_1_PROMPT_LINKS.md) and send it to the Implementer.
    - **Verify a completed task:** Find the report in the [Completion Report Index](reports/COMPLETION_REPORT_INDEX.md).
    - **Onboard a new agent:** Send them the link to the [Coordinator Handover Index](handover/HANDOVER_INDEX.md).

- **I am the Implementation Agent and I need to...**
    - **Start a new task:** Use the GitHub link provided by the Coordinator.
    - **Submit a completion report:** Follow the [Report Delivery Protocol](reports/REPORT_DELIVERY_PROTOCOL.md).
